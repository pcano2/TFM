Code accompanying the Master's Thesis (Trabajo Fin de Máster) submitted for the *Máster Universitario en Análisis de Datos Ómicos y Biología de Sistemas* (Universidad de Sevilla / Universidad Internacional de Andalucía).

## Overview

This repository contains the full analysis pipeline used to characterise the genomic and epigenetic context of transposases in 28 antibiotic-resistant clinical isolates of *Escherichia coli*.

The analysis integrates three sources of information for each strain:

- **Genome assemblies and annotations** in GenBank format (Oxford Nanopore sequencing, annotated with Prokka 1.14.6)
- **Methylation data** in wiggle format, produced with the Tombo alternative model, covering Dam (GATC) and Dcm (CCWGG) target motifs
- **Replicon assignment** (chromosome / plasmid) obtained with mlplasmids 2.2.0

From these, the pipeline extracts every coding sequence, identifies transposases, corrects frameshift-split transposase annotations, defines their immediate and extended genomic neighbourhood, classifies neighbouring genes functionally, and compares hypomethylation of transposases and their neighbours between replicons, against length-based expectations and between transposase- and gene-centred windows.

Everything is contained in a single R Markdown document that runs end to end.

## Repository structure

```
.
├── README.md
└── TFM.Rmd                  # Analysis document (the whole pipeline)
```

This repository holds the code only. Running it end to end also requires a local `Datos/` and `Resultados/` structure that is not included here (see *Data availability* below):

```
Datos/
├── genomas/
│   ├── GENBANK/              # Input .gbk files, one per strain
│   └── FASTA/                # Nucleotide FASTA, generated by code from the .gbk files
└── metilomas/                # Input Tombo .wig files (Dam and Dcm)

Resultados/
├── qc/
│   ├── quast/                # QUAST .tabular files (renamed from Galaxy's export folder)
│   └── checkm2.tabular       # CheckM2 report (renamed from Galaxy's export filename)
├── replicon/mlplasmid/       # mlplasmids output (resultados_replicon.csv), generated by code
├── proteinas_vecinas_CARD.fasta   # generated by the document itself (RGI input)
└── Resultado_RGI/            # RGI output, placed here manually
```

Galaxy exports the QUAST and CheckM2 reports under long, auto-generated names (with dataset numbers and an extra nested folder for QUAST). Rename them to `Resultados/qc/quast/` and `Resultados/qc/checkm2.tabular` after downloading, as above.

`proteinas_vecinas_CARD.fasta` is not an external input: the document writes it itself partway through the pipeline. The only manual step is running that file through RGI outside R and placing RGI's output file, under the exact name RGI gives it, inside `Resultados/Resultado_RGI/`.

## How to run

1. Place `TFM.Rmd` in a folder alongside the `Datos/` and `Resultados/` structure described above.
2. **First run only:** run the document up to the GenBank-to-FASTA conversion, then run QUAST and CheckM2 on the resulting FASTA files and place their reports in `Resultados/qc/` as described above.
3. **First run only:** run the document up to the export of `Resultados/proteinas_vecinas_CARD.fasta`, submit that file to RGI and place its output in `Resultados/Resultado_RGI/`.
4. Open `TFM.Rmd` in RStudio and click **Knit**.

Knitting writes the tables and figures to `Resultados/`.

## Analyses performed outside R

Three steps were run outside this document. Their outputs are expected under `Resultados/`, and the parameters used are documented in the Materials and Methods section of the thesis:

| Tool | Version | Where it was run | Input | Output goes to | Purpose |
|---|---|---|---|---|---|
| QUAST | 5.3.0 | Galaxy (usegalaxy.org) | Genome assemblies (`Datos/genomas/FASTA/`) | `Resultados/qc/quast/` | Assembly quality metrics |
| CheckM2 | 1.1.0 | Galaxy (usegalaxy.org) | Genome assemblies (`Datos/genomas/FASTA/`) | `Resultados/qc/checkm2.tabular` | Completeness and contamination |
| RGI / CARD | 6.0.5 / 4.0.1 | card.mcmaster.ca | `Resultados/proteinas_vecinas_CARD.fasta` (written by the document itself) | `Resultados/Resultado_RGI/` | Resistance gene identification |

Key settings: QUAST in reference-free mode with a 500 bp minimum contig length; CheckM2 in predict mode with the general model and DIAMOND database v1.0.2; RGI in protein mode with DIAMOND and CARD's Perfect and Strict criteria. All other parameters were left at default.

Methylation frequencies were estimated with the Tombo alternative model by the collaborating research team at Uppsala University and provided as wiggle files.

## Reproducibility

A fixed random seed (`set.seed(123)`) is set in the setup chunk. It only affects the random example rows shown in the report and the jittered points in some figures; no statistical result depends on it.

All file paths are relative to the folder containing `TFM.Rmd`.

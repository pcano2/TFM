**Epigenetic characterisation of the genomic context of transposases in antibiotic-resistant Escherichia coli
Code accompanying the Master's Thesis (Trabajo Fin de Máster) submitted for the Máster Universitario en Análisis de Datos Ómicos y Biología de Sistemas (Universidad de Sevilla / Universidad Internacional de Andalucía).**

Author: Pablo Cano Jiménez
 Supervisors: Francine Amaral Piubeli, María Antonia Sánchez Romero

 Academic year: 2025–2026


*Overview*
This repository contains the full analysis pipeline used to characterise the genomic and epigenetic context of transposases in 28 antibiotic-resistant clinical isolates of Escherichia coli.

The analysis integrates three sources of information for each strain:

Genome assemblies and annotations in GenBank format (Oxford Nanopore sequencing, annotated with Prokka 1.14.6)
Methylation data in wiggle format, produced with the Tombo alternative model, covering Dam (GATC) and Dcm (CCWGG) target motifs
Replicon assignment (chromosome / plasmid) obtained with mlplasmids 2.2.0

From these, the pipeline extracts every coding sequence, identifies transposases, defines their immediate and extended genomic neighbourhood, classifies neighbouring genes functionally, and tests whether hypomethylation is enriched around transposases relative to other genes.

Everything is contained in a single R Markdown document that runs end to end.


**Repository structure**
.

├── README.md

└── TFM.Rmd                  # Analysis document (the whole pipeline)

**This repository holds the code only. Running it end to end also requires a local Datos/ and Resultados/ structure that is not included here (see Data availability below):**

Datos/

├── genomas/

│   ├── GENBANK/              # Input .gbk files, one per strain

│   └── FASTA/                # Nucleotide FASTA, generated by code from the .gbk files

└── metilomas/                # Input Tombo .wig files (Dam and Dcm)

Resultados/

├── qc/

│   ├── quast/                # QUAST .tabular files (renamed from Galaxy's export folder)

│   └── checkm2.tabular       # CheckM2 report (renamed from Galaxy's export filename)

├── replicon/mlplasmid/       # mlplasmids output (resultados_replicon.csv), generated by code

├── proteinas_vecinas_CARD.fasta   # generated BY the document itself (RGI input) — not provided manually

└── Resultado_RGI/            # RGI output, placed here manually (input: proteinas_vecinas_CARD.fasta)

Galaxy exports the QUAST and CheckM2 reports under long, auto-generated names (with dataset numbers and an extra nested folder for QUAST). Rename them to Resultados/qc/quast/ and Resultados/qc/checkm2.tabular after downloading, as above.

proteinas_vecinas_CARD.fasta is not an external input: the document writes it itself partway through the pipeline. The only manual step is running that file through RGI outside R and placing RGI's output file, under the exact name RGI gives it, inside Resultados/Resultado_RGI/.

R packages

install.packages(c("tidyverse", "readODS", "patchwork", "gggenes", "janitor"))

Installed from Bioconductor:

if (!require("BiocManager")) install.packages("BiocManager")

BiocManager::install("Biostrings")

if (!require("devtools")) install.packages("devtools")

devtools::install_github("sirarredondo/mlplasmids")


**How to run**
Place TFM.Rmd in a folder alongside the Datos/ and Resultados/ structure described above.
Open TFM.Rmd in RStudio.
Click Knit.

Knitting writes the tables and figures to Resultados/.

**Reproducibility**
A fixed random seed (set.seed(123)) is set in the setup chunk.
All file paths are relative to the folder containing TFM.Rmd.


**Data availability**
Genome assemblies (GenBank .gbk), methylation wiggle files, and the intermediate QUAST/CheckM2/RGI outputs listed above are available from the corresponding authors upon reasonable request.
